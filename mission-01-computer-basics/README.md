# Mission 1 - Know your computer

## 1. Task / objective
Describe IPOS, identify hardware and software, and identify everyday computer-based systems.

## 2. Work completed
Completed the IPOS trace, hardware/software classification and everyday-system examples below.

### Task 1.1 - IPOS: typing and saving a document

| Stage | What happens | Possible hardware/component |
|---|---|---|
| Input | I press keys or select text. | Keyboard, mouse |
| Processing | The application interprets actions and updates the document in memory. | CPU, RAM |
| Output | The text appears on the screen. | Monitor |
| Storage | Saving writes the document to persistent storage. | SSD or other storage |

### Task 1.3 - Everyday computer-based systems

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Dispense cash and banking services | Card and PIN/buttons | Cash or receipt |
| Smart TV | Play and stream media | Remote or voice input | Picture and sound |

## 4. My understanding
IPOS describes a cycle: information enters a system, the CPU processes it using memory, the result is presented as output, and important results may be saved for later use.
